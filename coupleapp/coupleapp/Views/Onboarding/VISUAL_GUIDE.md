## Color Scheme

### Onboarding Pages

- **Welcome**: Pink gradient (heart icon)
- **Quests**: Blue gradient (clipboard icon)
- **Rewards**: Orange gradient (gift icon)
- **Events**: Green gradient (calendar icon)
- **Pairing**: Purple gradient (people icon)

### Tooltips

- **Background**: Blue to Purple gradient
- **Icon**: Yellow lightbulb
- **Text**: White
- **Dismiss**: White with opacity

### Empty States

- **Icon Circle**: Secondary gradient (from AppTheme)
- **Icon**: White
- **Title**: Primary text color
- **Description**: Secondary text color
- **CTA Button**: Primary gradient
- **Tips Card**: Card style with shadow

## Animation Details

### Onboarding

- **Page transitions**: Smooth swipe with spring animation
- **Icon appearance**: Scale and fade in
- **Button press**: Scale down to 0.95

### Tooltips

- **Appearance**: Slide down from top with spring animation
- **Dismissal**: Slide up with fade out
- **Auto-dismiss**: After 5 seconds
- **Response**: 0.6s spring with 0.7 damping

### Empty States

- **Appearance**: Scale and opacity transition
- **Icon**: Shadow with blur radius 10
- **Button press**: Scale effect with haptic feedback

## Accessibility

### VoiceOver Labels

- All icons have descriptive labels
- Buttons have clear action descriptions
- Tooltips announce their content
- Empty states provide context

### Dynamic Type

- All text scales with system font size
- Layouts adapt to larger text
- Minimum touch targets: 44x44 points

### Color Contrast

- Text meets WCAG AA standards
- Icons have sufficient contrast
- Gradients maintain readability

## User Experience Flow

```
New User Journey:
1. Sign up/Login
2. See Onboarding (5 pages)
3. Complete or Skip
4. Land on Dashboard
5. Navigate to Quest Board
6. See empty state with tips
7. Create first quest
8. See tooltip about completion
9. Complete quest
10. Navigate to Rewards
11. See empty state with ideas
12. Create first reward
... and so on
```

## Implementation Notes

### State Management

- OnboardingManager uses UserDefaults
- Singleton pattern for global access
- @Published properties for SwiftUI binding
- Automatic persistence on change

### Performance

- Lazy loading of onboarding view
- Delayed presentation (0.5s) for smooth UX
- Efficient state checks
- Minimal memory footprint

### Maintainability

- Modular components
- Reusable TipRow component
- Consistent styling via AppTheme
- Clear separation of concerns
