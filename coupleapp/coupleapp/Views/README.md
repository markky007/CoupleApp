# Views

This directory contains all SwiftUI views for the application.

## Structure

### Authentication
- `LoginView.swift` - Login screen
- `SignUpView.swift` - Registration screen
- `ForgotPasswordView.swift` - Password reset

### Main Features
- `DashboardView.swift` - Main dashboard
- `ProfileView.swift` - User profile and partner info
- `QuestBoardView.swift` - Quest list and management
- `RewardShopView.swift` - Reward catalog
- `EventListView.swift` - Events and anniversaries
- `TransactionHistoryView.swift` - Point transaction history

### Components
- `QuestRowView.swift` - Individual quest row
- `RewardRowView.swift` - Individual reward row
- `EventRowView.swift` - Individual event row
- `TransactionRowView.swift` - Individual transaction row

## Guidelines

- Keep views focused on UI only
- Use ViewModels for business logic
- Extract reusable components
- Use proper accessibility labels
- Follow SwiftUI best practices
