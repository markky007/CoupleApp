# Core

This directory contains core configuration and utilities.

## Structure

- `SupabaseConfig.swift` - Supabase client configuration
- `AppConstants.swift` - Application-wide constants (to be added)
- `Extensions/` - Swift extensions (to be added)
- `Utilities/` - Helper utilities (to be added)

## Guidelines

- Keep configuration centralized
- Use enums for constants
- Document all configuration values
- Separate development and production configs
